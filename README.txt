FRAME — Web Template Marketplace
================================
Mở index.html để chạy.

Cấu trúc:
- index.html: trang chủ
- products.html: kho template
- product.html: chi tiết sản phẩm
- login.html: giao diện đăng nhập
- css/style.css: toàn bộ style
- js/products.js: dữ liệu sản phẩm mẫu
- js/app.js: tìm kiếm, lọc, theme, chi tiết

Đây là bản frontend hoàn chỉnh để chạy trực tiếp trong SPCK.
Phần tài khoản, thanh toán, upload template và giao file cần backend/database khi triển khai bán thật.


LIEN HE: Trước khi công khai website, hãy thay hello@example.com trong các file HTML bằng email của bạn. Nút “Liên hệ” sẽ mở ứng dụng email của khách. Giá sản phẩm hiển thị bằng VNĐ.
